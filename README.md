Python Sentence Analyzer and Prime Number Checker

1. Project Introduction

This project is a simple Python program that analyzes a sentence and checks whether a given number is prime.

It was developed as part of the Level 1 Python Programming challenge.

2. Features

The program performs four main operations:

- Word Count: Counts the total number of words in a sentence.
- Longest Word: Identifies the longest word in the sentence.
- Sentence Reversal: Reverses the given sentence.
- Prime Number Checker: Determines whether the entered number is prime or not.

3. Technologies Used

- Programming Language: Python
- Editor: Programiz Online Python Compiler

4. Functions Used

Function| Description
"count_words()"- Counts words in a sentence.
"find_longest_word()"- Finds the longest word.
"reverse_sentence()"- Reverses the sentence.
"check_prime()"- Checks whether a number is prime.
"main()"- Runs the complete program.

5. How to Run

1. Install Python on your computer.
2. Download the "sentence_analyzer.py" file.
3. Open a terminal in the project folder.
4. Run the following command:

python sentence_analyzer.py

5. Enter a sentence and a number when prompted.

6. Sample Input

Sentence: I Love Learning Python

Number: 8

7. Expected Output

 Word Count: 4
 Longest Word: Learning
 Reversed Sentence: nohtyP gninraeL evoL I
 8 is not a Prime Number.

8. Decisions Made

 Used separate functions for each operation to keep the program organized.
 Used Python's "split()" method to count words.
 Used slicing to reverse the sentence.
 Used a mathematical approach to check prime numbers efficiently.
